# 2D 单位动画管线

## 资源入口
- 敌人：怪物表 `enemies.model_id` -> `res://assets/enemies/Models_2d/<ID>_备注/`
- 守护者：血脉表 `bloodlines.model_id` -> `res://assets/heroes/Models_2d/<ID>_备注/`
- 塔：血脉表 `bloodlines.model_id_point` -> `res://assets/heroes/point_2d/<ID>_备注/`
- 文件夹名只匹配 `_` 前的 ID，后半段只作人工备注。

## 基础文件名规则
没有 `anim_config.json` 时，运行时按 PNG 文件名关键词识别动画：

- 待机：`idle` / `stand` / `tower`
- 移动：`run` / `walk` / `move`
- 攻击：`attack` / `shoot` / `melee` / `cast`
- 死亡：`death` / `die`
- 受击：`hit` / `damage`
- 出生：`spawn`

如果一个状态匹配到多个 PNG，会按文件名排序后依次播放。例如 `Warrior_Attack1.png`、`Warrior_Attack2.png` 会作为同一次攻击动画连续播放。

## 序列帧切分
- 横向长条图：当图片宽度是高度的整数倍时，按正方形帧自动切分。
- 单帧图：不满足上述规则时，整张图作为一帧。
- 多行或非正方形帧：必须使用 `anim_config.json` 指定 `frame_width` / `frame_height`。

## 默认循环规则
- `idle`、`run` 默认循环。
- `attack`、`death` 默认不循环，播完后停在最后一帧。
- 需要覆盖时，在 `anim_config.json` 中设置 `loop`。

## 方向规则
运行时按移动/攻击方向选择文件名中的方向关键词：

- `down`
- `right`
- `up`
- `downright`
- `upright`

当前左方向会复用右方向文件并水平翻转。复杂八方向或不可翻转素材，后续在 `anim_config.json` 中显式配置。

`run/attack` 是强方向动作：没有方向关键词的 `Run.png` / `Attack.png` 只视为右方向资源，左方向可镜像复用；上、下、斜向没有对应资源时就是缺失，F6 会显示 `暂无`，运行时不会把同一张图兜底到所有方向。

`anim_config.json` 中显式填写的 `files` 也必须满足强方向规则；例如 `down.attack.files = ["Thief_Attack.png"]` 是错误配置，应改到 `right.attack` 或补对应 `Down` 方向素材。

攻击状态使用 `hit_frames` 数组表示多个命中帧，例如 `[3, 6]`。F6 中“切换当前命中帧”会加入或移除当前帧；运行时每个命中帧各触发一次，当前每次按攻击力 100% 结算。旧字段 `hit_frame` 只用于读取迁移，保存时写入 `hit_frames`。

## 可选 anim_config.json
每个模型文件夹可放一个 `anim_config.json`，用于覆盖自动识别。

```json
{
  "display_scale": 1.0,
  "visual_offset": [0, 0],
  "visual_ground_offset": 10,
  "animations": {
    "idle": {
      "files": ["Archer_Idle.png"],
      "fps": 8,
      "loop": true
    },
    "run": {
      "files": ["Archer_Run.png"],
      "fps": 10,
      "loop": true
    },
    "attack": {
      "files": ["Archer_Shoot.png"],
      "fps": 12,
      "loop": false
    },
    "death": {
      "files": ["Death.png"],
      "fps": 8,
      "loop": false
    }
  },
  "directions": {
    "down": {
      "attack": {
        "files": ["Lancer_Down_Attack.png"]
      }
    },
    "right": {
      "attack": {
        "files": ["Lancer_Right_Attack.png"]
      }
    },
    "up": {
      "attack": {
        "files": ["Lancer_Up_Attack.png"]
      }
    }
  }
}
```

## 程序职责边界
- `unit_sprite_animator.gd`：只负责读取模型文件夹、选择状态、播放序列帧。
- 敌人行为脚本：只负责何时开始攻击、何时结算伤害、何时结束攻击。
- 具体怪物特殊攻击、远程投射物、Boss 技能，不写进通用动画器；应新增独立行为脚本或技能脚本。

## 当前注意事项
- 攻击动画素材存在但看不到时，优先检查是否被行为脚本每帧重启。
- 新素材优先按文件名规则整理；只有方向复杂、帧尺寸特殊、缩放偏移不统一时再添加 `anim_config.json`。
