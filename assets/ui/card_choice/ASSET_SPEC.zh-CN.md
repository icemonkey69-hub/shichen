# 神权三选一资产规格

本文档是 `res://scenes/ui/神权三选一.tscn` 的正式资源规范。后续生成、替换、验收三选一资源时，先按这里的尺寸和安全区执行，不再自由生成。

## 设计基准

- 基准分辨率：`1440x810`
- 三选一主面板显示尺寸：`1220x660`
- 单张卡槽显示尺寸：`300x380`
- 卡牌显示比例：`15:19`
- 所有三选一运行时 UI 必须以独立场景为准：先在 `scenes/ui/神权三选一.tscn` 调整，再让 `game.gd` 只传数据和处理交互。

## 卡面安全区

以源图 `900x1140` 为准：

- Icon 区：`x=276..624, y=174..504`
- 标题区：`x=228..672, y=564..648`
- 描述区：`x=144..756, y=678..1014`
- 外框装饰区：可使用全图，但不得压住标题、icon 和描述区。
- 透明边界：外缘保留 `24px` 透明或半透明缓冲，避免缩放后贴边。
- 标题区和描述区必须偏灰或偏暗，保证白色字体不丢失可读性。

## 品阶色

- `1阶`：白 / 银白 / 冷灰白
- `2阶`：绿 / 翡翠绿
- `3阶`：蓝 / 冰蓝 / 深蓝
- `4阶`：紫 / 奥术紫
- `5阶`：橙 / 金橙
- `6阶`：红 / 深红

背景、卡框和 icon 背景都必须明显贴近对应品阶色，但主体颜色可以按卡牌语义变化。

六阶卡框必须是独立设计，不允许用同一张白框简单换色。品阶越高，材质复杂度、装饰密度、宝石/纹样层级和视觉稀有感应逐阶增强：

- `1阶`：银白、冷灰、珍珠/水晶，克制干净。
- `2阶`：银绿、藤蔓、叶片、翡翠，带自然圣遗物感。
- `3阶`：蓝银、冰晶、符文、能量线，明显比绿阶更锐利。
- `4阶`：暗银、紫晶、奥术裂片、虚空纹样，开始偏神秘和危险。
- `5阶`：金橙、日辉、羽翼/圣焰、琥珀宝石，显著华丽。
- `6阶`：黑红、熔岩裂纹、红宝石、尖刺/恶魔金属，最高稀有度冲击最强。

所有品阶卡框必须共用同一套安全区坐标；宝石、徽记、尖刺、羽翼、藤蔓、晶体等装饰不得进入标题文字区和描述文字区。

## 生成规则

- 卡框、按钮都必须按上表源图尺寸交付；选中反馈走 shader，不再额外交付位图序列帧。
- 同一类资源不允许每阶尺寸不同；旧资源若尺寸不同，替换时先统一尺寸再接入。
- 当前三选一背景使用静态单图，不接入背景动效；若未来重启背景动画，必须先做独立技术方案评审，不要直接在当前场景追加临时动效层。
- 卡牌 icon 永远按“一卡一张 512x512 单图”生成，不再使用拼图集切图作为正式方案。
- 生成图禁止带文字、数字、水印、UI 边框说明文字。
- 资源替换后必须在 `神权三选一.tscn` 里直接可见，再进游戏用 `F3` 或拾取神权机会验证同一画面。

## 未来美术资产生成规则

- 背景：只生成 `1920x1080` 静态整图，路径固定为 `res://assets/ui/card_choice/backgrounds/god_demon_choice_bg_v1.png`；画面左侧偏神圣/冷光，右侧偏地狱/熔岩，中间保留卡牌阅读空间。
- 卡框：只生成 `900x1140` 透明 PNG，路径固定为 `frames/tier_1_white.png` ~ `frames/tier_6_red.png`；六阶必须独立设计，不允许简单换色。
- 卡框透明通道：四角和外缘必须保持透明，真实可见外接框必须统一，避免运行时同尺寸 TextureRect 看起来大小漂移。
- 卡框安全区：Icon、标题、描述必须严格避让上文安全区；装饰、宝石、尖刺、羽翼、藤蔓、晶体不得压住文字区。
- 刷新按钮：只生成 `256x256` 透明 PNG 三态图，路径固定为 `buttons/refresh_button_normal.png`、`refresh_button_hover.png`、`refresh_button_disabled.png`；运行时显示为 `116x116`。
- 刷新按钮风格：命运齿轮/神权祭坛风格，中间必须保留暗色铭牌给 `刷新` 两字；悬停态增强金光，禁用态降饱和降亮度。
- 选中反馈：不生成光效序列帧；继续使用 `res://assets/shaders/card_choice_selected_highlight.gdshader` 根据卡框透明通道生成边缘高亮、斜向扫光和点击爆闪。
- 文本：名称与描述都由运行时代码自适应字号，不允许把文字画进美术图里。
- 产物清理：生成过程中的预览图、备份图、临时源图必须留在 `tmp/`，验收接入后删除；正式目录只保留当前场景直接引用的资源。

## 场景一致性规则

- `神权三选一.tscn` 是视觉真源；不要在 `game.gd` 中写卡槽布局。
- `res://scenes/ui/神权三选一卡牌.tscn` 是三选一卡槽 prefab；`神权三选一.tscn` 中的 `卡牌一..卡牌九` 必须实例化该场景。
- 运行时不允许再用脚本常量重写 icon、名称、描述的坐标和尺寸；这些位置必须来自 `神权三选一卡牌.tscn` 的可视化摆放。
- 根节点必须全屏锚定，主面板固定居中，运行时只允许脚本更新文字、icon、卡框纹理和交互状态。
- 若编辑器和运行时表现不一致，优先检查：是否改的是 `神权三选一卡牌.tscn` prefab、源图尺寸是否符合本规格、是否仍有脚本在改 Control 坐标、根节点是否仍为全屏锚点。
