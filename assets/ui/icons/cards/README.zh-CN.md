# 卡牌图标目录

这里存放卡牌背包使用的卡牌图标。

规则：
- 在 `Excel/cards#卡牌.xlsx` 里填写 `icon`
- 如果 `icon` 填 `1001`，程序会优先查找 `res://assets/ui/icons/cards/1001.png`
- 也支持同名的 `webp`、`jpg`、`jpeg`、`svg`
- 如果 `icon` 直接填写 `res://...` 完整路径，也会按该路径读取

建议：
- 优先使用 `PNG`
- 背景透明
- 推荐尺寸：`128x128`
- 最低建议：`96x96`
- 如果你想留更多后续裁切空间，可以直接出 `256x256`
