# 英雄资源目录

这里存放英雄、怪物和运行时展示相关资源。

## 当前目录

- `models_3d/`：F6 生成后的模型配置索引与按 ID 保存的配置。
- `portraits/`：英雄头像、立绘、小卡面。

## 当前 3D 管线

- 原始白模和动作不放进项目内，统一放在 `E:/Godot/model_3D/Ai_Model`。
- 原始武器模型不放进项目内，统一放在 `E:/Godot/model_3D/Ai_weapons`。
- F6 读取外部资源，调好动作、武器和挂点后，按 ID 保存到 `models_3d/`。
- 白模本体文件名必须带 `*_benti`；同文件夹内其他 GLB/FBX 都按动作读取。
