# assets 说明

这里是游戏运行时使用的美术资源目录。

规则：

- 放在这里的图片、材质、场景资源会被 Godot 导入，并生成 `.import` 文件。
- 程序、表格、场景引用的资源路径应指向这里。
- 原始 3D 白模、动作和武器不直接放进项目，统一放在 `E:/Godot/model_3D/`，由 F6 读取并生成项目内配置。

当前分类：

- `heroes/`：英雄头像与 F6 生成的 3D 配置。
- `enemies/`：敌人相关占位目录。
- `projectiles/`：飞行物和特效资源。
- `weapons/`：武器图标或运行时资源。
- `ui/`：界面图标与三选一界面资源。
