# assets 说明

这里是游戏运行时使用的美术资源目录。

规则：

- 放在这里的图片、材质、场景资源会被 Godot 导入，并生成 `.import` 文件。
- 程序、表格、场景引用的资源路径应指向这里。
- 旧 3D / 三渲二 / F6 动作表管线已废弃。F6 现在只作为 2D 序列帧查看器，不生成配置。

当前分类：

- `heroes/Models_2d/`：守护者 2D 序列帧资源，文件夹名格式为 `<ID>_备注`。
- `heroes/point_2d/`：塔 2D 序列帧资源，文件夹名格式为 `<ID>_备注`。
- `enemies/Models_2d/`：敌人 2D 序列帧资源，文件夹名格式为 `<ID>_备注`。
- `pickups/`：金币、经验等拾取物资源。
- `projectiles/`：飞行物和特效资源。
- `weapons/`：武器图标或运行时资源。
- `ui/`：界面图标与三选一界面资源。
